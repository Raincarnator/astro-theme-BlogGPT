# 交互式文章目录

## 短横线与预览

宽屏阅读页左侧显示短横线，长度对应标题层级。鼠标移动到哪一条，该条就位移并加深，同时显示章节摘要；移开后恢复为当前阅读章节加深。

点击短线跳到对应章节，按住左键上下移动可连续定位。

## 完整目录

指针在同一短线上静止一段时间后展开完整目录，也可以点击展开按钮。目录显示在视口左侧中央，悬停条目与短线同步高亮。

圆角虚线框标出当前屏幕中出现的章节。即使标题已滚出，只要该节正文仍可见，就会被框选。按住左键沿条目移动可快速跳转。

点击目录外部、关闭按钮、选择章节或按 Escape 关闭。鼠标离开后等待 `hideDelay` 自动收起；焦点在目录内部时保持展开。

## 配置

在 `article.toc` 中设置：

```ts
toc: {
  enabled: true,
  minDepth: 2,
  maxDepth: 4,
  expandDelay: 1000,
  hideDelay: 800,
}
```

`minDepth`、`maxDepth` 选择 H1–H6 的收录范围，默认 H2–H4。`expandDelay` 是指针静止后的展开等待时间，`hideDelay` 是离开后的收起等待时间，单位均为毫秒。

单篇通过 `toc: true` 或 `toc: false` 覆盖全局开关。目录沿用正文标题的锚点。

## 窄屏

窄屏时，RSS 左侧显示目录按钮。点击后，完整目录从右上角展开，支持同样的章节框选和按住拖动定位。

窄屏面板保持打开，直到点击外部、关闭按钮、目录按钮、某一章节或按 Escape。系统设置减少动态效果时，目录省略过渡动画。
