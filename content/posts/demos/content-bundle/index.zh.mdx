文章、独立页面、分类和标签都保存在 `content/` 中。用文件夹整理内容，再通过 frontmatter 设置标题、地址和其他信息。

## 四类内容

| 目录                  | 用途                         |
| --------------------- | ---------------------------- |
| `content/posts/`      | 文章                         |
| `content/pages/`      | 独立页面与功能页介绍         |
| `content/categories/` | 分类的名称、简介、封面和正文 |
| `content/tags/`       | 标签的名称、简介、封面和正文 |

每类内容都支持 Markdown、MDX 和嵌套目录。

## 文件与地址

普通文件使用 `hello.md` 或 `hello.mdx`；需要图片和附件时，可以建一个文件夹，用 `index.md` 或 `index.mdx` 作为内容包入口。

`slug` 决定内容的地址。例如 `slug: content-bundle` 对应默认语言前缀策略下的 `/zh/posts/content-bundle/`。移动管理目录后，显式设置的 slug 保持不变。

## 文章信息

```yaml
title: 一篇示例文章
slug: example
date: 2026-01-01
description: 用一句话介绍文章。
categories: [guide]
tags: [astro, content]
image: ./cover.webp
featured: true
```

`categories` 和 `tags` 使用分类、标签的 slug；`featured: true` 将文章放入侧栏的置顶区域。日期与发布状态见[发布与迁移](../migration/)。

## 多语言内容

在同一目录使用 `index.zh.mdx`、`index.en.md` 等语言后缀文件，即可为同一篇内容提供译文。独立文件同样支持 `hello.zh.md`、`hello.en.mdx` 这样的命名方式。

语言菜单会打开对应内容。更多语言的配置与添加方法见[语言与翻译](https://bloggpt.reincarnatey.net/content/languages)。

## 写作模板

```sh title="Terminal"
pnpm new post my-first-post --title "我的第一篇文章"
pnpm new post a-bundle --use bundle --title "带附件的文章"
pnpm new page contact --use bundle
```

使用 `post`、`page`、`category`、`tag` 选择内容类型，`--title` 设置标题，`--use` 选择模板。模板放在 `archetypes/`，可以按自己的写作习惯调整。
