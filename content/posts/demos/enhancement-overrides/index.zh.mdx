公式、图表、图片灯箱、提示块、目录和分享封面都支持全局设置与单篇覆盖。

## 全局默认值

在 `blog.config.ts` 的 `article` 中设置各项默认值。其中目录使用 `toc.enabled`，自动分享封面使用 `shareCover.enabled`。

## 单篇覆盖

在文章或独立页面的 frontmatter 中填写需要调整的项目：

```yaml
math: true
mermaid: false
lightbox: true
callouts: true
toc: true
shareCover: false
```

`true` 开启，`false` 关闭，省略的字段继承全局设置。只需填写要修改的项目。

## 各开关的作用

| 字段         | 功能                |
| ------------ | ------------------- |
| `math`       | KaTeX 公式          |
| `mermaid`    | Mermaid 图表        |
| `lightbox`   | PhotoSwipe 图片灯箱 |
| `callouts`   | Callouts 提示块     |
| `toc`        | 文章目录            |
| `shareCover` | Satori 自动分享封面 |

关闭公式、图表或提示块增强时，对应内容以源码或普通引用显示。关闭自动分享封面时，分享预览使用已设置的文章封面。

[文章增强](../article-enhancements/)可以体验这些功能，标题与作者等信息的显示设置见[正文显示](../display-options/)。
