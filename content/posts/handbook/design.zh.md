BlogGPT 将查找内容、阅读正文和分享文章放在连贯的交互中。下面介绍日常浏览时可以使用的操作。

## 找到一篇文章

首页和搜索面板都能查找内容。默认搜索范围为“文章”；“标题”仅包含文章的标题与简介，“正文”仅包含文章的正文，“全站”则包含文章、分类、标签、独立页面。

匹配发生在正文时，搜索结果会附带上下文，点击可以跳到对应段落。

## 补全命令和文章

输入 `/` 显示匹配命令；输入 `@` 按全部公开文章的标题补全。

| 命令          | 功能                            |
| ------------- | ------------------------------- |
| `/random`     | 随机打开一篇近期公开文章        |
| `/lang en`    | 切换界面语言                    |
| `/theme dark` | 切换外观，也可用 light / system |
| `/status`     | 打开博客统计                    |
| `/categories` | 打开分类列表                    |
| `/archives`   | 打开归档                        |

## 快捷键

| 快捷键                       | 功能           |
| ---------------------------- | -------------- |
| `Ctrl+K` / `⌘+K`             | 打开搜索       |
| `Ctrl+Shift+S` / `⌘+Shift+S` | 开关侧栏       |
| `Ctrl+Shift+O` / `⌘+Shift+O` | 返回首页       |
| `Shift+Esc`                  | 聚焦首页输入框 |
| `Ctrl+/` / `⌘+/`             | 查看快捷键     |

支持使用鼠标和方向键（聚焦时）拖动调整侧栏的宽度。

## 沿目录阅读

左侧短线长度对应标题层级，移动鼠标可以预览章节。

点击“展开文章目录”，或将指针放在同一短线上一段时间后自动展开完整目录，窄屏中则需点击顶部展开按钮。虚线框标记了当前在屏幕中出现的章节范围，按住左键沿目录移动可以快速定位。

## 分享

悬停或聚焦“分享”查看封面、复制链接，点击分享按钮会复制可配置格式的分享文字，选择分享至社交平台时会跳转到对应社交平台的分享页面。

## 站点统计

通过左下角作者菜单或在首页对话中输入 `/status` 打开统计面板。
