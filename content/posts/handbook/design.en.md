BlogGPT connects finding content, reading and sharing in a continuous browsing experience. These are the controls available during everyday browsing.

## Find an article

The homepage and search panel both find content. The default scope is “Articles”; “Titles” includes only article titles and descriptions, “Body” includes only article bodies, and “Everywhere” includes articles, categories, tags and standalone pages.

Body matches include surrounding context. Click a passage to jump to the matching paragraph.

## Complete commands and articles

Type `/` to show matching commands, or `@` to complete titles from all public articles.

| Command       | Action                                                 |
| ------------- | ------------------------------------------------------ |
| `/random`     | Open a random recent public article                    |
| `/lang en`    | Switch the interface language                          |
| `/theme dark` | Change appearance; light and system are also available |
| `/status`     | Open blog statistics                                   |
| `/categories` | Open the category index                                |
| `/archives`   | Open the archives                                      |

## Keyboard shortcuts

| Shortcut                     | Action                   |
| ---------------------------- | ------------------------ |
| `Ctrl+K` / `⌘+K`             | Open search              |
| `Ctrl+Shift+S` / `⌘+Shift+S` | Toggle the sidebar       |
| `Ctrl+Shift+O` / `⌘+Shift+O` | Return home              |
| `Shift+Esc`                  | Focus the homepage input |
| `Ctrl+/` / `⌘+/`             | View keyboard shortcuts  |

Resize the sidebar by dragging its edge, or using arrow keys when the resize control is focused.

## Follow the outline

The short lines on the left reflect heading depth. Move over them to preview sections.

Click “Expand article outline”, or pause on the same line to expand the full outline automatically. On narrow screens, use the button at the top. A dashed frame marks the sections currently visible on screen. Hold the left mouse button and move along the outline to navigate quickly.

## Sharing

Hover or focus “Share” to view the cover and copy a link. Click the main button to copy a message in the configured format. Choosing a social platform opens its sharing page.

## Site statistics

Open statistics from the bottom-left author menu or by entering `/status` in the homepage input.
